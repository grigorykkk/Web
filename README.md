# Заметки PWA

В данном проекте я разработал учебное PWA-приложение для управления задачами и заметками в рамках практических занятий по дисциплине «Фронтенд и бэкенд разработка».

При выполнении работы я последовательно реализовал функции, которые рассматривались в практических занятиях №13-17: офлайн-режим, Web App Manifest, запуск через HTTPS, архитектуру App Shell, обмен данными через WebSocket, push-уведомления и напоминания.

## Описание выполненной работы

### Практическое занятие №13. Service Worker

В этой работе я добавил `Service Worker`, который кэширует основные ресурсы приложения, перехватывает запросы и обеспечивает работу в офлайн-режиме.

### Практическое занятие №14. Web App Manifest

На этом этапе я создал файл `manifest.json`, настроил основные параметры приложения и подключил его в `index.html`, чтобы сайт можно было устанавливать на устройство как PWA.

### Практическое занятие №15. HTTPS + App Shell

Далее я настроил запуск приложения по HTTPS и реализовал архитектуру `App Shell`, благодаря которой интерфейс загружается быстрее, а основное содержимое подгружается динамически.

### Практическое занятие №16. WebSocket + Push

На этом этапе я реализовал сервер на `Node.js` и `Express`, подключил `Socket.IO` для обмена данными в реальном времени и настроил push-уведомления через `web-push`.

### Практическое занятие №17. Детализация Push

На заключительном этапе я добавил напоминания для задач, планирование уведомлений на сервере и возможность отложить напоминание на 5 минут через push-уведомление.

## Что умеет приложение

После выполнения всех практических заданий моё приложение поддерживает:

- создание новых задач;
- добавление описания к задаче;
- установку напоминания;
- отметку задач как выполненных;
- удаление отдельных задач;
- удаление всех выполненных задач;
- фильтрацию задач по статусу;
- отображение статистики;
- сохранение данных в `localStorage`;
- синхронизацию задач с сервером;
- push-уведомления;
- работу в офлайн-режиме;
- установку приложения на устройство.

## Запуск проекта

Для запуска проекта необходимо:

1. Установить зависимости:

```bash
npm install
```

2. Запустить сервер:

```bash
npm start
```

3. Открыть приложение в браузере:

- `http://localhost:3001`
- или `https://localhost:3443`, если используются локальные сертификаты.
