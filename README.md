# TaskFlow PWA

Учебное приложение для заметок, доработанное по требованиям практических занятий 15 и 16:

- `App Shell` с динамической загрузкой страниц из `content/`;
- офлайн-режим через `Service Worker` и отдельные кэши для оболочки и контента;
- `localStorage` для хранения заметок;
- realtime-синхронизация между вкладками через `Socket.IO`;
- push-уведомления через `Push API` и `web-push`;
- поддержка локального `HTTPS`, если рядом с проектом лежат `localhost.pem` и `localhost-key.pem`.

## Запуск

1. Установите зависимости:

```bash
npm install
```

2. Запустите сервер:

```bash
npm start
```

3. Откройте приложение:

- `http://localhost:3001`, если сертификатов нет;
- `https://localhost:3443`, если вы положили в корень проекта `localhost.pem` и `localhost-key.pem`.

## HTTPS для практики №15

Для полностью доверенного локального HTTPS удобнее использовать `mkcert`, как в методичке:

```bash
mkcert -install
mkcert localhost 127.0.0.1 ::1
```

После генерации переименуйте или оставьте файлы как:

- `localhost.pem`
- `localhost-key.pem`

и снова запустите `npm start`.

## Проверка требований

1. Откройте DevTools -> `Application` -> `Service Workers` и убедитесь, что `sw.js` зарегистрирован.
2. Проверьте `Cache Storage`: должны появиться кэши оболочки и динамического контента.
3. Добавьте заметку и обновите страницу: запись останется в `localStorage`.
4. Откройте вторую вкладку приложения и добавьте заметку в первой: во второй появится realtime-уведомление.
5. Включите push-уведомления кнопкой в интерфейсе и разрешите их в браузере.
6. При наличии HTTPS и разрешения на уведомления новые задачи будут приходить как системные push-уведомления.
