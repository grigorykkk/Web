# TaskFlow PWA

Простое приложение для управления задачами и заметками.

Реализовано:

- просмотр списка задач и заметок;
- добавление новых задач;
- хранение данных в `localStorage`;
- офлайн-работа через `Service Worker`;
- `Web App Manifest` и набор PNG-иконок для установки как PWA.

## Запуск

Приложение нужно открывать через локальный HTTP-сервер, иначе `Service Worker` не
зарегистрируется.

Пример запуска:

```bash
node app.js
```

После запуска откройте в браузере `http://127.0.0.1:4173`.

## Проверка требований

1. Добавьте несколько задач и перезагрузите страницу: данные сохранятся.
2. Откройте DevTools -> `Application` -> `Service Workers` и убедитесь, что воркер активен.
3. Отключите сеть в DevTools и обновите страницу: приложение продолжит открываться из кэша.
4. Откройте DevTools -> `Application` -> `Manifest`: браузер должен видеть манифест и иконки.
5. Установите приложение через кнопку установки в браузере: оно откроется в отдельном окне.
